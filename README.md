# Hangman Game 🎮
A simple Python Hangman game made by Areeba Saddique.

## How to Play
- The game chooses a random word
- You guess letters one by one
- You have 6 chances
- Guess the word before chances run out!

## How to Run
python test.py

## Features
- You Win / You Lose messages
- Wrong guess tracking
- Simple and beginner friendly
